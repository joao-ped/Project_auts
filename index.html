Funcionalidades

O que o aparelho faz

Tudo desenhado para uso real: botões grandes, feedback tátil, frases compostas e bateria recarregável.

🎯
7 categorias · 35 palavrasNecessidades, Sentimentos, Ações, Comidas, Lugares, Pessoas, Saúde
✍
Frases compostasEmpilhe até 5 palavras e fale tudo de uma vez. Ex: "Eu quero" + "Beber" + "Água".
🔊
Controle de volumePotenciômetro analógico ajusta o volume em tempo real, de 0 a 30.
🔋
Bateria recarregável18650 com módulo TP4056. Ícone no LCD mostra o nível atual.
📳
Feedback tátilMotor de vibração confirma cada ação, mesmo se o usuário não olhar o display.
💤
Modo sleepLCD apaga após 2 min sem uso. Qualquer botão acorda o aparelho.
🔒
Auto-detecção I2CFunciona com diferentes módulos LCD (0x27, 0x3F, 0x20, 0x38) sem alterar código.
⚙
Configuração fácilSeção dedicada no .ino para personalizar categorias e palavras conforme o usuário.
Como se usa

5 botões coloridos

Mapeamento direto: cor → função. Sem menus complicados, sem texto a memorizar.

Sobre

Voz Autista é um projeto open source de comunicação assistiva para pessoas autistas não-verbais.

Hardware Arduino, código livre, case impresso em 3D.
