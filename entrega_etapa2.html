1. Evidências de progresso

O projeto está em fase avançada de desenvolvimento. Toda a parte de software, documentação, simulação e modelagem 3D está concluída. Resta apenas a montagem física do hardware, agendada para a próxima etapa.

✓ 1.1 Código firmware Arduino — CONCLUÍDO

Arquivo voz_autista_maker_code.ino com 589 linhas, totalmente funcional.

  • 7 categorias com 35 palavras (Necessidades, Sentimentos, Ações, Comidas, Lugares, Pessoas, Saúde)
  • Frases compostas (empilha até 5 palavras)
  • Controle de volume via potenciômetro analógico (A0)
  • Monitor de bateria com ícone no LCD (divisor de tensão em A1)
  • Feedback tátil via motor de vibração + transistor 2N2222 (D7)
  • Modo sleep após 2 min de inatividade
  • Auto-detecção do endereço I2C do LCD (0x27, 0x3F, 0x20, 0x38)

✓ 1.2 Documentação técnica — CONCLUÍDA

Três documentos principais cobrem todo o projeto:

  • README.md — visão geral, materiais, pinagem, instruções
  • GUIA_IMPLEMENTACAO.md (26 KB) — guia completo de implementação
  • manual_montagem_visual.html (125 KB) — 10 etapas com diagramas SVG incluindo plano do case 3D, vistas laterais com cotas, esquemático elétrico completo e troubleshooting

✓ 1.3 Simulação no Wokwi — CONCLUÍDA

Permite testar o código Arduino sem hardware físico.

  • diagram.json com 18 partes e 27 conexões (Arduino, LCD I2C, 5 botões, buzzer, LED, potenciômetros, resistores, microSD)
  • sketch.ino adaptado com mesma pinagem do hardware real
  • abrir_no_wokwi.html — página assistente que importa o circuito em 3 cliques
  • COMO_USAR.md — 5 métodos de import documentados

✓ 1.4 Simulador no navegador (TTS) — CONCLUÍDO

simulador.html — usa a Web Speech API para reproduzir as palavras com síntese de voz, permitindo demonstrar o produto em qualquer navegador, sem hardware.

✓ 1.5 Apresentação interativa — CONCLUÍDA

apresentacao.html — slides navegáveis com visão geral, motivação, hardware e diferenciais.

✓ 1.6 Case 3D paramétrico — MODELO PRONTO

Arquivo OpenSCAD case_3d/case_voz_autista.scad (456 linhas). Dimensões internas 170 × 110 × 42 mm.

  • Base: pilares M3, berço para 18650, suporte do motor, aberturas USB, jack, micro-USB TP4056, chave on/off, slot microSD e furo do potenciômetro
  • Tampa: janela do LCD 72×25 mm, 5 furos para botões Ø14 mm, grade do speaker Ø40 mm, labels em relevo (CAT+, CAT-, PAL+, PAL-, VOZ)
  • visualizar_case_3d.html — viewer 3D no navegador

✓ 1.7 Site do projeto (GitHub Pages) — CONCLUÍDO

index.html — landing page hub com 6 cards (Apresentação, Manual, Simulador, Wokwi, Case 3D, Código). Configurado para hospedagem.

URL prevista: https://joao-ped.github.io/Project_auts/
